# AI Ops Glossary

## LLM

Large Language Model

Example:
Incident Analysis Assistant

## Prompt

Instructions given to AI

## Context

Operational information supplied to AI

## RAG

Retrieve information before generating answers

## Grounding

Using trusted evidence

## Hallucination

Incorrect AI output

## Tool Calling

AI uses approved operational tools

## AI Agent

AI that can reason and use tools

## AI-SRE

AI-assisted Site Reliability Engineering
