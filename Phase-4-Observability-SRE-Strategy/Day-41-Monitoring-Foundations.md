# Day 41 - Monitoring Foundations

## What is Monitoring?

Monitoring is the process of observing systems to understand health, performance, and availability.

## Why Monitoring?

- Detect issues early
- Reduce downtime
- Improve reliability
- Support troubleshooting

## Three Pillars of Observability

### Metrics

Numerical measurements collected over time.

Examples:
- CPU Usage
- Memory Usage
- Request Count

### Logs

Records of events that occurred inside systems.

Examples:
- User Login
- API Request
- Error Messages

### Traces

Track a request as it moves through multiple services.

Examples:
- Frontend
- API
- Database

## Key Learning

Metrics tell what is wrong.

Logs tell what happened.

Traces tell where it happened.
