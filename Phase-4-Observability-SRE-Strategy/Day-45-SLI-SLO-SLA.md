# Day 45 - SLI, SLO, SLA

## Reliability

Ability of a system to perform correctly over time.

## Availability vs Reliability

Availability:
Can users access the service?

Reliability:
Does the service work correctly?

## SLI

Service Level Indicator.

Measurement.

Example:
99.8% successful requests

## SLO

Service Level Objective.

Target.

Example:
99.9% availability

## SLA

Service Level Agreement.

Customer-facing promise.

Example:
99.9% uptime guarantee

## Error Budget

100% - SLO

Example:

SLO = 99.9%

Error Budget = 0.1%

## Key Learning

SLI measures reality.
SLO defines target.
SLA defines promise.
